1. Overview

LumenStudio is a creative Chrome extension for producing animated light paintings using particle trails, force fields, exposure, bloom, palettes, and pointer-driven motion. Its purpose is to provide a self-contained visual art instrument inside the extension popup.

The extension is designed to work entirely within the browser's extension popup. It does not require an online account, cloud service, developer-operated backend, advertising network, analytics platform, social login, or remote content service in order to provide its core functionality.

Short version: LumenStudio does not collect, transmit, sell, rent, or share personal information. Creative processing takes place locally on your device.

2. Scope of This Policy

This Privacy Policy applies to the Chrome extension named LumenStudio, including its popup interface, local creative engine, controls, generated visual output, and any files the user explicitly chooses to export through the browser.

This policy does not apply to unrelated websites, other extensions, Chrome itself, the Chrome Web Store, your operating system, or services operated by Google or other third parties. Those products may process information under their own terms and privacy policies independently of LumenStudio.

If a future version of LumenStudio adds functionality that materially changes its data practices, this policy will be updated before or alongside that change.

3. Information We Collect

LumenStudio does not collect personal information or user data for the developer. There is no developer-operated database or server receiving extension usage information.

In particular, the extension does not intentionally collect identifiers, names, email addresses, IP addresses, account information, device identifiers, browser history, search history, web page contents, location, financial information, health information, authentication credentials, personal communications, or advertising identifiers.

The developer does not receive a copy of your artwork, your interactions with the creative controls, or your generated output through the extension.

5. Local Processing

Creative calculations are performed locally using code packaged with the extension. This includes drawing operations, canvas rendering, procedural or simulated effects, parameter changes, visual composition, and other interactive behavior required to produce the extension's output.

Local processing means the working data needed to render the current creative session remains within the browser process on your device rather than being sent to a developer-controlled service.

Closing the popup may end the current in-memory session depending on the extension's current state. The extension does not use a developer-operated cloud save system.

6. LumenStudio-Specific Data Handling

LumenStudio generates animated light paintings inside a local canvas using particles, trails, force fields, palettes, exposure, bloom, motion, and pointer gestures. These visual calculations occur in the browser on your device.

Pointer gestures and force fields

Pointer position, dragging, and clicks inside the LumenStudio canvas may be used to place particles, create force fields, or control motion. Those coordinates are temporary creative inputs and are not sent to the developer or used for tracking.

Animation state

Particles, attraction or repulsion fields, trail state, exposure values, palette selections, and other rendering parameters exist locally so that the live artwork can be drawn. The developer does not receive a live stream or recording of the canvas.

PNG export

When you explicitly choose to save the artwork, LumenStudio converts the current canvas to PNG locally and asks the browser to download the resulting file. The image is not uploaded to a developer server as part of that process.

Any later use of the exported image—such as opening it in an editor, syncing it to cloud storage, or posting it online—is outside the extension and is governed by the privacy practices of the services you choose.

No access to web content

LumenStudio operates only in its own popup and does not inspect the content of your active tab, read website text, collect URLs, or inject effects into third-party pages.

7. Chrome Permissions

The current Chrome version of LumenStudio does not request optional or required Chrome extension permissions. Its Manifest V3 package does not ask for access to tabs, browsing history, active websites, downloads, storage, cookies, geolocation, clipboard data, notifications, or other sensitive browser APIs.

The extension also does not request host permissions such as <all_urls> or access to specific websites. Its functionality is contained within its own popup.

Why this matters: limiting permissions reduces the amount of browser information an extension is technically able to access and helps keep the extension's single purpose isolated from unrelated browser activity.

8. Storage and Retention

LumenStudio does not maintain a developer-controlled database of user information and therefore does not impose a server-side retention period for personal data.

Temporary visual state may exist in browser memory while the extension is open. If the extension provides an explicit export action, the resulting file is created only after the user initiates that action. The exported file is then handled by the browser and operating system as a local file under the user's control.

Because no personal information is collected by the developer, there is no developer-held user profile to retain, retrieve, or delete.

9. Data Transmission and Network Requests

The extension's packaged code does not require a developer backend and is designed without external network requests for its creative functionality. It does not upload artwork, creative parameters, usage events, or identifiers to a developer-operated server.

No remote JavaScript, remote stylesheet, external font, analytics endpoint, tracking pixel, advertising request, or cloud rendering service is required by the extension.

Chrome itself, the Chrome Web Store, your operating system, security software, or your network environment may independently perform their own network activity. Such activity is outside the control and scope of LumenStudio.

10. Data Sharing, Disclosure, and Sale

Because LumenStudio does not collect user data for the developer, the developer does not sell, rent, license, monetize, disclose, or share extension user data with advertisers, data brokers, analytics companies, social networks, or other third parties.

There is no cross-context behavioral advertising, targeted advertising profile, data brokerage, or user-data marketplace associated with the extension.

If disclosure were ever legally required in relation to information actually held by the developer, the developer would respond only to valid legal obligations. At present, the extension is intentionally designed so that the developer does not receive the categories of user data described above.

11. Third-Party Services and External Code

LumenStudio does not integrate third-party analytics, advertising, authentication, crash-reporting, social media, cloud storage, or AI services into its core extension package.

The extension does not rely on externally hosted executable code. Its functionality is delivered from files packaged with the extension.

If you download or save an image and later open or share that file using another application or online service, the privacy practices of that separate application or service apply to your subsequent use of the file.

13. Security

The extension follows a data-minimization approach: the most reliable way to reduce privacy risk is to avoid collecting unnecessary user data in the first place.

LumenStudio keeps its creative processing local, does not require a user account, does not request broad host permissions, and does not transmit creative content to a developer server. These design choices substantially limit the categories of information available to the extension.

No software can be guaranteed to be completely free of defects or security risks. Users should keep Chrome and installed extensions updated and obtain the extension only from sources they trust.
