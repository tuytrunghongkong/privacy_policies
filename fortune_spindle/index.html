Privacy Policy for Fortune Spindle

Last updated: August 22, 2026

This Privacy Policy explains how information is handled when you install, access, or use the Fortune Spindle browser extension.

Fortune Spindle is a lightweight entertainment extension that provides a glowing ornate wheel within a browser toolbar popup. Users can spin the wheel to reveal randomly selected fortunes and use lock and reset controls to manage the current result and start a new spin.

Fortune Spindle is designed as a simple, self-contained experience. Its core functionality does not require users to create an account or provide personally identifiable information.

Privacy Summary

Fortune Spindle does not require an account, payment information, or personal profile in order to use its core fortune-spinning features.

Wheel spins, randomly selected fortunes, lock controls, and reset actions are used only to provide the entertainment functionality requested by the user.

Fortune Spindle is not designed to use browsing activity for advertising, behavioral profiling, or cross-site tracking.

1. Scope of This Privacy Policy

This Privacy Policy applies specifically to the Fortune Spindle browser extension and the functionality provided directly through its toolbar popup.

It does not govern unrelated websites, browser vendors, operating systems, extension marketplaces, or other third-party services independently used by the user.

2. Core Purpose of Fortune Spindle

The primary purpose of Fortune Spindle is to provide a simple interactive fortune wheel that users can access directly from the browser toolbar.

The extension displays a decorative glowing wheel that can be spun to reveal a randomly selected fortune.

Controls are also provided to lock a result or reset the wheel so that the user can continue interacting with the extension.

3. Information We Require

Fortune Spindle does not require personally identifiable information for its standard functionality.

Users are not required to provide:

  • Full name;

4. No Account Required

Fortune Spindle does not require users to create a dedicated account in order to access its standard fortune wheel.

Users do not need to register a username, password, profile, or email address simply to spin the wheel or view a fortune.

5. Toolbar Popup Interface

Fortune Spindle is designed to operate through a compact popup that opens when the user activates the extension from the browser toolbar.

The toolbar popup contains the controls and visual elements required to operate the fortune wheel.

Users can interact with the extension without navigating away from the webpage they are currently viewing.

6. Fortune Wheel Functionality

The main interactive element in Fortune Spindle is a decorative wheel that responds to user-initiated spin actions.

When a spin occurs, the extension determines a result and displays a fortune selected from the available fortune content.

Functional values used during a spin may include:

  • Wheel position;
  • Animation state;
  • Spin duration;
  • Selected result;
  • Current fortune;
  • Lock state;
  • Reset state; and
  • Other temporary interface values.

7. Random Fortune Selection

Fortune Spindle uses a random or pseudo-random selection process to choose a fortune when the user spins the wheel.

Randomization is used purely as part of the entertainment experience.

A fortune result is not intended to represent a factual prediction about the user or provide personalized analysis based on personal information.

8. Fortune Content

Fortunes displayed by the extension are intended for casual entertainment and creative enjoyment.

The extension does not require personal information in order to select or display a fortune.

Fortune results are not generated from a user's browsing history, financial information, private communications, health information, or other sensitive personal data.

9. Lock Control

Fortune Spindle includes a lock control that allows the user to keep a current fortune or wheel state visible.

The lock state is a functional application value used only to control the user interface.

Locking a fortune does not create a personal profile or identify the user.

10. Reset Control

Fortune Spindle also includes a reset control that allows users to clear the current wheel state and begin a new interaction.

Reset functionality may restore the wheel, current fortune, animation, lock state, or related interface values to their initial state.

This functionality is used only to manage the extension's entertainment experience.

11. Temporary Application State

While Fortune Spindle is open, the extension may temporarily maintain information required to operate the wheel correctly.
