Privacy summary

Color on the page, control with the user

chromafall wash is designed around a user-triggered full-page visual effect. The extension uses active-tab access and scripting to apply the wash after user interaction and uses browser storage to retain supported settings locally.

01

Scope of This Privacy Policy

This Privacy Policy explains how information is accessed, processed, stored, and handled when you install or use the chromafall wash browser extension.

chromafall wash applies a bright full-page rainbow wash effect to the active webpage. The effect cycles through colors and may be customized using controls for strength and shimmer speed.

Users access the controls through the extension's toolbar popup, and the declared visual effect is applied after user interaction.

This Privacy Policy applies to chromafall wash itself and does not govern unrelated websites, browser vendors, operating systems, or independent third-party services.

02

Single Purpose

chromafall wash has a focused single purpose: providing a customizable ambient rainbow wash across the webpage selected by the user.

Functionality reasonably related to this purpose may include:

  • Displaying a full-page color overlay;
  • Cycling through rainbow colors;
  • Creating shimmer transitions;
  • Adjusting effect strength;
  • Adjusting shimmer speed;
  • Enabling or disabling the wash;
  • Applying the effect to the active tab;
  • Removing the effect when requested; and
  • Saving customization settings locally.
03

No Account Required

chromafall wash does not require users to create a dedicated account in order to use its standard visual functionality.

Users do not need to provide a username, password, email address, personal profile, or other identity information simply to activate or customize the effect.

04

Browser Permissions

chromafall wash declares browser permissions necessary to provide its user-triggered visual functionality and preserve extension settings.

activeTab Provides temporary access to the currently active browser tab after the user invokes the extension.
scripting Allows chromafall wash to execute the code necessary to apply, update, or remove the declared rainbow wash effect.
storage Allows extension settings to be saved locally in the user's browser.
05

activeTab Permission

chromafall wash uses the activeTab permission only when the user invokes the extension on the currently active tab.

This temporary access enables the extension to apply its declared visual effect to the page the user is viewing.

The permission is not intended to provide permanent access to every website visited by the user.

User-triggered page access

The active tab is accessed in connection with an intentional extension action initiated by the user.

06

scripting Permission

chromafall wash uses the scripting permission to run code required for the declared rainbow wash effect.

Script execution may be used to:

  • Create the visual overlay;
  • Apply color transitions;
  • Control shimmer animation;
  • Adjust effect intensity;
  • Apply updated settings;
  • Maintain the effect while active; and
  • Remove the effect when requested.

The scripting permission is intended to support chromafall wash's disclosed visual feature rather than unrelated monitoring.

chromafall wash creates a full-page ambient color effect across the active webpage.

The extension may create one or more visual layers that cover or blend with the viewport to produce the rainbow wash described in the extension listing.

The purpose of these visual layers is decorative and user-facing.

Overlay state Used to determine whether the effect is currently active.
