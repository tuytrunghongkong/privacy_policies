Privacy Policy for talcum ritual

Last updated: August 22, 2026

This Privacy Policy explains how information is accessed, processed, stored, and handled when you install or use the talcum ritual browser extension.

talcum ritual is a visual customization extension that enhances the browsing experience by displaying soft white talcum dust textures that pulse rhythmically across the background of the currently active webpage.

Users can activate and customize the visual effect through the extension's toolbar popup. The extension uses limited browser permissions to apply the effect only after the user initiates an action, while customization settings are stored locally in the user's browser for convenience.

Privacy Summary

talcum ritual does not require users to create an account or provide personal information to use its core functionality.

The extension uses activeTab only after user interaction, uses scripting to apply its declared visual effect to the active page, and uses storage to save extension settings locally in the browser.

The permissions are intended solely to provide the extension's user-facing visual customization features.

talcum ritual uses browser permissions that are directly related to its disclosed functionality.

scripting Permission

talcum ritual uses the scripting permission to execute the code necessary to display its visual effect on the currently active tab after the user initiates an action.

Script execution allows the extension to add, update, or remove the talcum dust textures and related animation elements required by the extension's declared feature.

storage Permission

talcum ritual uses the storage permission to save extension preferences locally in the user's browser.
