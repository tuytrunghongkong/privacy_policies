Privacy summary

Magnification initiated by the user

LensCraft uses a context-menu command, temporary active-tab access, and user-triggered script execution to display a circular magnifying lens around selected text. The selected text is processed as necessary to provide the requested enlargement and brightness effect.

01

Scope of This Privacy Policy

This Privacy Policy explains how information is accessed, processed, and handled when you install or use the LensCraft browser extension.

LensCraft provides a circular magnifying lens overlay that enlarges and brightens text intentionally selected by the user.

The extension is activated through a browser right-click context menu action and operates on the currently active tab after user interaction.

This policy applies to LensCraft itself and does not govern unrelated websites, browser vendors, operating systems, or independent third-party services.

02

Single Purpose

LensCraft has a focused single purpose: improving the readability of text deliberately selected by the user through a circular magnification overlay.

Functionality reasonably related to this purpose may include:

  • Detecting text intentionally selected by the user;
  • Providing a right-click LensCraft action;
  • Creating a circular magnifying overlay;
  • Enlarging selected text;
  • Brightening the magnified area;
  • Displaying a subtle glow ring;
  • Positioning the lens near the selected content;
  • Updating the overlay as necessary; and
  • Removing the lens when the interaction ends.
03

No Account Required

LensCraft does not require users to create a dedicated personal account in order to use its standard functionality.

Users do not need to provide a username, password, email address, personal profile, or other identity information merely to magnify selected text.

04

Selected Text

LensCraft operates on text that the user deliberately selects before invoking the extension.

The selected content may be used to determine what text should be displayed inside or beneath the magnifying overlay.

A typical LensCraft interaction may involve:

  • Selecting a word, sentence, or other text;
  • Opening the browser's right-click menu;
  • Choosing the LensCraft action;
  • Identifying the selected text;
  • Creating the circular lens overlay; and
  • Displaying an enlarged and brightened representation.
User-selected scope

LensCraft's core interaction is based on text deliberately selected by the user rather than arbitrary page content chosen by the extension.

05

Types of Selected Content

Depending on the webpage and the user's choice, selected text may technically include:

  • Public webpage text;
  • Article content;
  • Descriptions;
  • Labels;
  • Instructions;
  • Notes;
  • Form text;
  • Messages; or
  • Other textual content deliberately selected by the user.

LensCraft does not need to decide independently which text should be magnified. The user controls the selection.

06

Selected Text and Sensitive Information

Because the user controls what is selected, selected text could technically contain personal, confidential, or sensitive information.

Avoid selecting unnecessary sensitive information

Users should avoid invoking LensCraft on passwords, authentication codes, private keys, financial credentials, government identifiers, or other highly sensitive information unless there is a clear and appropriate reason to do so.

07

Browser Permissions

LensCraft declares browser permissions necessary to provide its user-triggered magnification functionality.

contextMenus Used to add LensCraft's right-click action so the user can deliberately invoke the magnifying lens for selected text.
activeTab Provides temporary access to the currently active tab after the user invokes LensCraft.
scripting Allows LensCraft to execute the code necessary to create, display, update, or remove the magnifying overlay.
08

contextMenus Permission

LensCraft uses the contextMenus permission to add a LensCraft command to the browser's right-click menu.

This provides a clear user-controlled mechanism for activating the extension.

LensCraft is not intended to automatically magnify arbitrary text across every webpage without a relevant user action.

09

activeTab Permission

LensCraft uses the activeTab permission only in connection with the user's interaction on the currently active browser tab.

This temporary access allows LensCraft to identify the selected text and display the requested magnification effect on that page.

The permission is intended to provide user-triggered access rather than permanent access to all browsing activity.

10

scripting Permission

LensCraft uses the scripting permission to execute code required for its declared magnifying-lens feature.

Script execution may be used to:

  • Identify the selected text or selection location;
  • Create the circular overlay;
  • Display enlarged text;
  • Apply brightness enhancement;
  • Render the glow ring;
  • Position the lens;
  • Update the overlay; and
  • Remove the LensCraft interface when appropriate.

This permission is intended to support the extension's disclosed readability function rather than unrelated monitoring.

11

Circular Magnifying Lens

LensCraft creates a circular visual overlay that enlarges the text selected by the user.

The lens may be positioned relative to the selected content so that users can read the magnified version while remaining on the current webpage.

The overlay is part of the extension's user interface and is intended only to provide a temporary readability enhancement.

12

Text Enlargement

LensCraft may render selected text at a larger size inside the magnifying lens.

Functional values used for magnification may include:

Selected text Determines what content is displayed in enlarged form.
Selection position Helps determine where the lens should appear.
Magnification level Determines the visual enlargement applied to the selected text.
Overlay state Determines whether the LensCraft interface is currently visible.
13

Brightness Enhancement

LensCraft may brighten the magnified text or background within the lens in order to improve visibility.

Brightness-related processing may include visual styling, contrast adjustment, background treatment, opacity, or other presentation properties.

These values are visual interface settings rather than personal information.

14

Glow Ring

LensCraft displays a subtle glow ring around the circular magnifying overlay.

The glow is a decorative and functional interface element intended to distinguish the magnified area from the surrounding webpage.

Glow-related rendering may include color, opacity, blur, intensity, and other visual properties.

15

Temporary Lens State

While LensCraft is active, the extension may temporarily maintain information necessary to display the magnification interface.

Temporary functional state may include:

  • The selected text;
  • The position of the selection;
  • The lens position;
  • The enlarged text state;
  • Brightness or styling values;
  • Glow-ring properties;
  • Visibility state; and
  • Other temporary interface values.
16

Interaction With the Active Webpage

LensCraft interacts with the currently active webpage in order to identify user-selected text and display the magnifying overlay.

Such interaction is intended to be limited to what is reasonably necessary to provide the requested readability enhancement.

LensCraft does not need to build a permanent archive of the webpage simply to display a temporary magnifying lens.

17

Website Content

LensCraft may interact with page content because its purpose is to magnify text selected directly on the webpage.

This does not mean the extension needs to collect or archive all text, images, videos, documents, or other content appearing on the page.

The extension's disclosed purpose is centered on the specific text deliberately selected by the user.

18

Browsing History

LensCraft does not require a complete history of websites visited by the user in order to magnify selected text.

The extension is not designed to maintain a browsing-history profile for advertising, behavioral analysis, or unrelated commercial purposes.

19

Search History

General search-engine history is not required for LensCraft's magnification functionality.

Search queries performed on unrelated websites are not necessary for rendering the circular lens.

20

Forms and Editable Fields

LensCraft may technically be invoked on text contained in an editable field when the user deliberately selects that text and chooses the LensCraft context-menu action.

The extension is not intended to automatically collect every value entered into webpage forms simply because LensCraft is installed.

Users should exercise particular care when selecting text inside:

  • Login forms;
  • Payment forms;
  • Medical forms;
  • Private messages;
  • Account-management interfaces; or
  • Other sensitive input areas.
21

Keystrokes

LensCraft is not designed to operate as a keystroke logger.

The extension does not need to continuously record keyboard activity across unrelated websites in order to provide its core functionality.

LensCraft is centered on text deliberately selected by the user.
